## 🚀 At a Glance
Power-user for Windows is an add-in that extends Microsoft PowerPoint, Excel and Word with a large library of ready-made content and time-saving tools. It installs a dedicated ribbon tab so you can insert templates, icons, charts and maps and tidy your formatting without ever leaving your document. If you have ever wanted to be a genuine power user in Office, this add-in gives you the shortcuts to get there while keeping the workflow you already know.

## ✨ What You Get
| Feature | What it does for you |
|---------|----------------------|
| Template library | Start from professional slides and layouts instead of a blank file. |
| Icons and flags | Insert thousands of vector icons and country flags and recolour them instantly. |
| Advanced charts | Build Gantt, waterfall, Mekko and other visuals beyond the native Office set. |
| Editable maps | Add country and regional maps shaded by value for clear reporting. |
| Formatting tools | Align, resize and standardise objects and colours across a whole file fast. |

## 📥 Install Guide
1. Click the **Download** button above to get the latest Power-user installer.
2. Run the installer and follow the on-screen steps to add Power-user to your Office suite.
3. Open PowerPoint, Excel or Word and select the new **Power-user** tab in the ribbon. Sign in to activate a Premium plan if you have one.

## 🎯 Quick Start
1. Open your presentation, workbook or document in the Office app.
2. Click the **Power-user** tab in the ribbon.
3. Insert a template, icon, chart or map from the galleries.
4. Adjust colours, text and layout, then use the formatting tools to polish the file.

## ❓ FAQ
**Is Power-user free?**
Power-user is freemium. The free version includes a broad set of tools, and a paid Premium plan unlocks the full template, icon, chart and map libraries. You can download and use it without paying to get started.

**Which versions of Windows are supported?**
Power-user works on currently supported 64-bit editions of Windows 10 and Windows 11 inside a supported version of Microsoft PowerPoint, Excel or Word.

**Is my data secure?**
Power-user operates within your own Office applications, so your documents stay in your usual storage. Refer to the official Power-user website for full details on privacy and data handling.
